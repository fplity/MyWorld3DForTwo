# 方块奇境 3D（Java）

一个完全使用 Java 标准库制作的第一人称 3D 体素沙盒。无需 Maven、Gradle 或额外游戏引擎，安装 JDK 17+ 即可运行。

## 开始游戏

在 PowerShell 中运行：

```powershell
.\run-game.ps1
```

也可以双击 `run-game.bat`。首次启动会生成一个新世界，之后自动读取 `saves/world.mw3d`。

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 观察 |
| 左键长按 | 挖掘方块 / 攻击史莱姆 |
| 右键 | 放置选中的方块 |
| 空格 | 跳跃；飞行时上升 |
| Shift | 奔跑；飞行时下降 |
| 1–9 / 滚轮 | 选择方块 |
| E | 打开背包与合成 |
| F | 切换飞行模式 |
| Y | 手动切换天气 |
| F5 | 保存世界 |
| Esc | 暂停 / 释放鼠标 |

主菜单检测到已有存档时，按 `Enter` 继续，或按 `N` 生成一个全新的世界。

背包界面使用 `↑/↓` 选择配方，按 `Enter` 合成。游戏每 30 秒自动保存。

## 世界内容

- 程序化丘陵、海滩、湖水、树林、花朵、洞穴和矿脉
- 17 种方块，包含玻璃、砖、发光方块和稀有矿石
- 昼夜循环、星空、太阳/月亮、动态雾效和雨天
- 重力、跳跃、游泳、碰撞、生命值和挖掘进度
- 方块背包、九格快捷栏、五种合成配方和镐子升级
- 会追逐玩家的史莱姆、夜间萤火虫，以及一个不会写在这里的探索惊喜
- 二进制世界存档、自动保存、死亡重生

## 测试

```powershell
.\test.ps1
```
