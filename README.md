# 方块奇境 3D（Java）

一个完全使用 Java 标准库制作的第一人称 3D 体素沙盒。无需 Maven、Gradle 或额外游戏引擎，安装 JDK 17+ 即可运行。

## 开始游戏

在 PowerShell 中运行：

```powershell
.\run-game.ps1
```

也可以双击 `run-game.bat`。首次启动会生成一个新世界，之后自动读取 `saves/world.mw3d`。

仓库自带已验证的 `dist/MyWorld3D.jar`。只想直接玩时，安装 Java 17+ 后双击 `play.bat`，无需重新编译；也可在项目根执行 `java -jar dist/MyWorld3D.jar`。修改源码后执行 `build.ps1` 重新打包。

本项目是单人、有限世界的原创体素沙盒，不包含官方 Minecraft 资源。

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 观察 |
| 左键长按 | 挖掘方块 / 攻击史莱姆 |
| 右键 | 放置选中的方块 |
| 空格 | 跳跃；飞行时上升 |
| Shift | 奔跑；飞行时下降 |
| 1–9 / 滚轮 | 选择当前页槽位 / 循环全部 15 种可建造方块 |
| E | 打开背包与合成 |
| F | 切换飞行模式 |
| Y | 手动切换天气 |
| F5 | 保存世界 |
| Esc | 暂停 / 释放鼠标 |

主菜单检测到已有存档时，按 `Enter` 继续，或按 `N` 生成一个全新的世界。新建前会把原档保存在 `saves/world-before-new-*.mw3d`；备份失败则取消新建。退出游戏会等待最终存档完成。窗口失焦会自动暂停。

背包界面使用 `↑/↓` 选择配方，按 `Enter` 合成。游戏每 30 秒自动保存。

## 世界内容

- 程序化丘陵、海滩、湖水、树林、花朵、洞穴和矿脉
- 17 种方块，包含玻璃、砖、发光方块和稀有矿石
- 昼夜循环、星空、太阳/月亮、动态雾效和雨天
- 重力、跳跃、游泳、碰撞、生命值和挖掘进度
- 方块背包、分页九格快捷栏、七种合成配方和镐子升级
- 会追逐玩家的史莱姆、夜间萤火虫，以及一个不会写在这里的探索惊喜
- 二进制世界存档、自动保存、死亡重生

世界默认大小为 112×48×112，渲染分辨率为 480×270，再放大至窗口；最高 60 FPS。玻璃和水目前使用颜色着色，未实现透明折射、流体模拟和动态局部光照。生物以朝向相机的像素精灵渲染。没有联机、无限区块或声音资源系统；遗迹提示中的“音乐”是文字氛围提示。

## 存档与恢复

新存档采用 v3：CRC32 校验、尺寸/方块/玩家/库存检查、临时写入与原子替换。可读取旧 v1/v2 存档。每次成功覆盖前保留上一版 `world.mw3d.bak`；主档损坏时保留坏档并尝试恢复备份，原档无法安全保留时禁止覆盖保存。

本次上传还保留了项目原有玩家存档，见 [archive/saves/world.mw3d](archive/saves/world.mw3d)。克隆仓库后，关闭游戏并执行以下命令即可恢复原世界；若已经创建自己的新世界，请先另存 `saves/world.mw3d`。

```powershell
New-Item -ItemType Directory -Force saves | Out-Null
Copy-Item archive\saves\world.mw3d saves\world.mw3d
```

日常存档和编译缓存仍被 Git 忽略，归档存档单独保留。

## 测试

```powershell
.\test.ps1
```

自动回归包含 23 组，检查实际旧存档、数据损坏、备份、输入状态、生成、合成、碰撞、采集、放置、战斗及渲染。需要检查桌面窗口时执行 `test-desktop.ps1`；它使用隔离临时存档，并生成菜单、游戏、背包和暂停截图。

详细更新与验收范围见 [CHANGELOG.md](CHANGELOG.md) 和 [项目完成说明.md](项目完成说明.md)。

渲染器采用低分辨率体素光线投射后进行像素化放大，因此既保持纯 Java 零依赖，也保留了方块游戏的复古质感。
